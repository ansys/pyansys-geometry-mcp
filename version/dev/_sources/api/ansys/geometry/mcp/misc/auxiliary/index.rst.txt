.. py:function:: resolve_bodies(app_context: ansys.geometry.mcp.context.PyAnsysGeometryContext, design: ansys.geometry.core.designer.design.Design, body_ids: list[str] | None = None, named_selection: str | None = None, selection_handle: str | None = None) -> tuple[list[ansys.geometry.core.designer.body.Body], str | None]

   Resolve the bodies a tool should act on from IDs or a selection.

   Precedence is ``selection_handle``, then ``named_selection``, then
   ``body_ids``, and then every body in the design.

   On success, a ``bodies = ...`` line is appended to the command history. It
   replays the lookup the caller asked for (the selection, the named selection,
   the supplied IDs, or every body) rather than the IDs it resolved to, so the
   script stays valid when the design is rebuilt and IDs change.

   Parameters
   ----------
   app_context : PyAnsysGeometryContext
       Application state, which is used to look up ``selection_handle`` and to
       record the command history.
   design : Design
       Active design to resolve against.
   body_ids : list of str, default: None
       Body IDs, as reported by ``list_entities``.
   named_selection : str, default: None
       Label of a named selection whose bodies should be used.
   selection_handle : str, default: None
       Handle of a selection builder from the ``create_selection_builder`` method.

   Returns
   -------
   tuple[list[Body], str | None]
       ``(bodies, error)``. ``error`` is ``None`` on success; otherwise the
       body list is empty and the string is meant to be returned to the caller.
